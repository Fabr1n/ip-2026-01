## Executando um exercício

Com Go instalado, execute cada arquivo separadamente. Exemplo:

```bash
git clone https://github.com/Fabr1n/ip-2026-01.git
cd ip-2026-01
go run "Lista_02/atividade1.go"
```

As listas contêm programas independentes; executar a pasta inteira pode causar conflito entre funções `main`.
